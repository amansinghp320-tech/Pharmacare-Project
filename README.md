# 💊 PharmaCare – Medical Store Management System

**PharmaCare** is a web-based Medical Store Management System designed to help manage medicines, inventory, sales, customers, and suppliers through a simple and user-friendly dashboard.

The project provides a centralized interface for monitoring medicine stock, identifying low-stock and expired medicines, and managing daily medical store operations.

---

## 🚀 Features

### 📊 Dashboard

* View total number of medicines
* Monitor low-stock medicines
* Track expired medicines
* View current inventory
* Search medicines
* Add new medicines/stock

### 💊 Inventory Management

* Add medicines
* Manage medicine quantities
* Track batch numbers
* Track selling prices
* Manage expiry dates
* Monitor stock status

### 💰 Sales Management

* Manage medicine sales
* Track sales information
* View selling details

### 👥 Customer Management

* Store customer information
* Manage customer records

### 🚚 Supplier Management

* Manage supplier information
* Track medicine suppliers

### ⚙️ Settings

* Manage application settings

## 🖥️ Dashboard

The PharmaCare dashboard provides important information at a glance:

* **Total Medicines**
* **Low Stock Items**
* **Expired Items**
* **Current Inventory**

The inventory table displays:

| Field         | Description                   |
| ------------- | ----------------------------- |
| ID            | Unique medicine ID            |
| Medicine Name | Name of the medicine          |
| Batch No.     | Medicine batch number         |
| Quantity      | Available stock quantity      |
| Selling Price | Selling price of the medicine |
| Expiry Date   | Medicine expiry date          |
| Status        | Current stock status          |

---

## ➕ Add New Medicine

The dashboard includes an **Add New Medicine** feature where users can enter:

* Medicine Name
* Batch Number
* Quantity
* Selling Price
* Expiry Date

After entering the required information, the stock can be saved using the **Save Stock** button.

---

## 🔍 Search Medicine

Users can search for medicines using the search box available on the dashboard.

This helps store staff quickly find medicine records from the inventory.

## ▶️ How to Run the Project

### Method 1 – Directly in Browser

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `dashboard.html`.
4. Run it in your browser.

### Method 2 – Using Live Server

1. Install the **Live Server** extension in VS Code.
2. Open the project folder.
3. Right-click `dashboard.html`.
4. Select **Open with Live Server**.

The application will open in your browser.
